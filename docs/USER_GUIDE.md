## 快速开始

### 系统要求
- **操作系统**: Windows 10/11, macOS 10.14+, Linux
- **Python 版本**: Python 2.7 或 Python 3.7+
- **硬件要求**: 支持 OpenGL 2.0+ 的显卡，至少 2GB 内存

### 安装步骤

1. **下载项目**: 克隆或下载游戏项目到本地

2. **安装依赖**:
   ```bash
   cd 1024game
   pip install -r requirements.txt
   ```
   
   或单独安装:
   ```bash
   pip install pygame
   pip install numpy
   pip install pygame-menu
   pip install pygame-gui
   ```

3. **启动游戏**:
   ```bash
   python main.py
   ```

## 游戏安装

### Windows 系统

1. 安装 Python (推荐 Python 3.10+):
   - 下载地址: https://www.python.org/downloads/
   - 安装时勾选 "Add Python to PATH"

2. 打开命令提示符 (CMD):
   ```cmd
   cd path/to/1024game
   pip install -r requirements.txt
   python main.py
   ```

### macOS 系统

1. 安装 Homebrew (如未安装):
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

2. 安装 Python:
   ```bash
   brew install python
   ```

3. 安装依赖:
   ```bash
   cd path/to/1024game
   pip3 install -r requirements.txt
   python3 main.py
   ```

### Linux 系统

1. 安装 Python 和 Pygame 依赖:
   ```bash
   sudo apt update
   sudo apt install python3 python3-pip python3-dev python3-numpy
   sudo apt install libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev
   sudo apt install libsdl2-ttf-dev libportmidi-dev libswscale-dev libavformat-dev
   sudo apt install libavcodec-dev zlib1g-dev
   ```

2. 安装游戏依赖:
   ```bash
   cd path/to/1024game
   pip3 install -r requirements.txt
   python3 main.py
   ```

## 游戏玩法

### 游戏目标

- 合并数字方块，达到当前关卡的目标值
- 目标值根据关卡难度递增:
  - 关卡 1-5: 目标值 128
  - 关卡 6-10: 目标值 256
  - 关卡 11-15: 目标值 512
  - 关卡 16-20: 目标值 1024

### 基本规则

1. **移动方块**: 使用方向键或 W/A/S/D 控制所有方块向同一方向移动
2. **合并规则**: 当两个相同数字的方块碰撞时，它们会合并成一个数字翻倍的新方块
3. **新方块**: 每次移动后，会在空白位置随机生成一个新的方块（2 或 4）
4. **得分计算**: 每次合并都会获得相应的分数（合并后的数字值）
5. **游戏结束**: 当无法再移动方块时，游戏结束

### 游戏策略

1. **保持方块有序**: 尽量保持数字方块按大小顺序排列
2. **控制最大数字**: 将最大数字保持在一个角落
3. **规划移动**: 每次移动前考虑后续几步
4. **利用空格**: 保持一定的空格，增加移动灵活性
5. **避免小数字分散**: 小数字分散会限制移动空间

### 难度说明

游戏共 20 个关卡，分为 4 个难度等级:

#### 初级难度 (关卡 1-5)
- 目标值: 128
- 4 的生成概率: 10%
- 最大方块数: 12 个
- 特点: 适合新手熟悉游戏规则

#### 中级难度 (关卡 6-10)
- 目标值: 256
- 4 的生成概率: 15%
- 最大方块数: 14 个
- 特点: 难度适中，需要一定策略

#### 高级难度 (关卡 11-15)
- 目标值: 512
- 4 的生成概率: 20%
- 最大方块数: 16 个
- 特点: 挑战性强，需要精准控制

#### 专家难度 (关卡 16-20)
- 目标值: 1024
- 4 的生成概率: 25%
- 最大方块数: 20 个
- 特点: 高难度，考验玩家技巧

## 操作说明

### 键盘控制

| 按键 | 功能说明 |
|------|----------|
| ↑ / W | 向上移动方块 |
| ↓ / S | 向下移动方块 |
| ← / A | 向左移动方块 |
| → / D | 向右移动方块 |
| ESC | 暂停游戏 / 返回菜单 |
| R | 重新开始当前关卡 |
| 空格键 | 继续游戏（暂停时） |

### 鼠标控制

主菜单和设置界面使用鼠标操作:
- **左键点击**: 选择菜单选项、调整设置
- **拖拽**: 拖动滑块调整音量、帧率等
- **滚轮**: 滚动菜单（如有多个选项）

### 游戏界面元素

1. **游戏区域**: 显示 4x4 的游戏网格
2. **分数显示**: 当前得分和目标值
3. **关卡显示**: 当前关卡编号
4. **时间显示**: 游戏时长
5. **操作提示**: 当前游戏状态提示
6. **暂停按钮**: 点击暂停游戏

## 主菜单功能

### 开始游戏
- 点击 "开始游戏" 进入第一关
- 或点击 "关卡选择" 选择特定关卡

### 关卡选择
- 显示所有 20 个关卡
- 已通关关卡显示为绿色
- 未通关关卡显示为灰色
- 点击关卡按钮直接进入该关卡

### 游戏设置
- **主题切换**: 选择不同的视觉主题
- **音量调节**: 
  - 音乐音量: 控制背景音乐音量
  - 音效音量: 控制游戏操作音效音量
- **显示设置**:
  - FPS 限制: 调整游戏帧率（30-144 FPS）
  - 显示 FPS: 开启/关闭 FPS 显示
- **特效设置**:
  - 粒子特效: 开启/关闭合并、升级等特效
  - 3D 音效: 开启/关闭 3D 音效效果
- **语言设置**: 选择游戏语言（目前仅支持中文）

### 成就系统
- 显示所有可解锁的成就
- 已解锁成就显示金色图标
- 未解锁成就显示灰色图标
- 悬停显示成就描述和解锁条件

### 教程指南
- 详细的游戏规则说明
- 操作指南和快捷键说明
- 游戏策略建议

### 退出游戏
- 点击 "退出" 按钮关闭游戏
- 所有进度和设置会自动保存

## 游戏设置

### 主题定制

游戏支持多种视觉主题:

1. **经典主题**: 经典 2048 游戏配色
2. **深色主题**: 深色背景，护眼模式
3. **彩色主题**: 多彩方块，活泼风格
4. **简约主题**: 极简设计，清爽界面

### 音频设置

1. **音乐音量**: 0-100% 调节背景音乐音量
2. **音效音量**: 0-100% 调节游戏操作音效
3. **3D 音效**: 开启后音效会根据位置变化（模拟 3D 空间）

### 显示设置

1. **FPS 限制**:
   - 30 FPS: 低性能设备推荐
   - 60 FPS: 标准设置（默认）
   - 144 FPS: 高性能设备可选

2. **显示 FPS**: 在游戏界面左上角显示当前帧率

### 特效设置

1. **粒子特效**:
   - 合并特效: 方块合并时的粒子动画
   - 升级特效: 通关时的庆祝动画
   - 游戏结束特效: 游戏结束时的动画

2. **3D 音效**: 音效会根据方块位置变化音量和方向

## 数据持久化

### 自动保存

游戏会自动保存以下数据:

1. **游戏进度**:
   - 已通关关卡
   - 每个关卡的最高分
   - 当前游戏状态（如暂停时）

2. **用户设置**:
   - 主题选择
   - 音量设置
   - 显示选项
   - 特效开关

3. **统计数据**:
   - 累计游戏时间
   - 总移动次数
   - 总合并次数
   - 游戏胜负统计

### 数据存储位置

游戏数据保存在 `data/` 目录下:
- `settings.json`: 配置文件
- `progress.json`: 游戏进度
- `high_score.txt`: 高分记录

### 数据恢复

如遇数据丢失，可:
1. 检查 `data/` 目录是否存在
2. 确认文件权限（可读写）
3. 尝试从备份恢复（如有）

## 常见问题

### Q1: 游戏启动失败

**可能原因**:
- Python 未正确安装
- 依赖包未安装或版本不兼容
- 显卡驱动不支持

**解决方法**:
```bash
# 检查 Python 版本
python --version

# 重新安装依赖
pip install --upgrade pygame
pip install --upgrade pygame-menu
```

### Q2: 游戏运行卡顿

**可能原因**:
- 电脑配置较低
- 后台运行程序过多
- FPS 设置过高

**解决方法**:
1. 在设置中降低 FPS 限制（如 60 FPS → 30 FPS）
2. 关闭粒子特效
3. 关闭其他后台程序
4. 升级显卡驱动

### Q3: 没有声音

**可能原因**:
- 音量设置为 0
- 音频设备未正确连接
- Pygame 音频初始化失败

**解决方法**:
1. 检查系统音量
2. 在游戏设置中调整音量
3. 重启游戏或音频设备

### Q4: 游戏进度丢失

**可能原因**:
- 游戏异常退出
- 文件权限问题
- 杀毒软件误删

**解决方法**:
1. 确保正常退出游戏（点击退出按钮）
2. 检查 `data/` 目录权限
3. 添加游戏目录到杀毒软件白名单

### Q5: 无法选择关卡

**可能原因**:
- 关卡数据损坏
- 游戏文件不完整

**解决方法**:
1. 验证游戏文件完整性
2. 重新下载游戏
3. 删除 `data/progress.json` 并重新开始

### Q6: 键盘无法控制

**可能原因**:
- 输入法问题
- 焦点不在游戏窗口
- 键盘按键冲突

**解决方法**:
1. 切换到英文输入法
2. 点击游戏窗口获得焦点
3. 检查键盘硬件连接
