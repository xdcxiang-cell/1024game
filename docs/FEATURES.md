# 1024 游戏 - 功能特性文档

## 项目概述

1024 游戏是一款基于 Pygame 的现代化数字合成游戏，具有精美的图形界面、流畅的游戏体验和丰富的功能特性。

## 核心功能

### 1. 游戏玩法
- **经典 2048 机制**: 使用方向键或 W/A/S/D 控制数字方块移动
- **数字合成**: 相同数字碰撞会合并并翻倍
- **目标达成**: 每个关卡有特定目标值，达到目标即可通关
- **20 个关卡**: 分为 4 个难度等级（每 5 关提升一次难度）

### 2. 难度系统
- **智能难度算法**: 根据关卡动态调整游戏参数
- **难度等级**:
  - 关卡 1-5: 基础难度，目标值 128
  - 关卡 6-10: 中等难度，目标值 256
  - 关卡 11-15: 困难难度，目标值 512
  - 关卡 16-20: 专家难度，目标值 1024
- **难度参数调整**:
  - 4 的生成概率从 10% 逐渐增加到 25%
  - 最大方块数量从 12 个增加到 20 个

### 3. 图形界面
- **Pygame 渲染**: 高性能图形引擎
- **60FPS 流畅运行**: 多线程渲染确保游戏流畅
- **主题定制**: 支持多种视觉主题
- **粒子特效**: 合并、升级、游戏结束等场景的粒子动画

### 4. 音效系统
- **3D 音效模拟**: 沉浸式音频体验
- **音效反馈**: 移动、合并、升级等操作的音效
- **音量控制**: 音乐和音效独立调节

### 5. 游戏界面
- **主菜单**: 游戏入口、关卡选择、设置、成就等功能
- **关卡选择**: 支持选择 20 个关卡中的任意一个
- **游戏界面**: 显示游戏区域、分数、目标、时间等信息
- **暂停菜单**: 支持游戏暂停和继续
- **游戏结束界面**: 显示最终成绩和统计数据

### 6. 成就系统
- **多种成就**: 涵盖游戏时长、分数、关卡等多个维度
- **成就跟踪**: 自动记录游戏进度并解锁成就
- **成就展示**: 在菜单中查看已解锁和未解锁的成就

### 7. 数据持久化
- **游戏进度保存**: 自动保存当前游戏状态
- **设置保存**: 保存用户的主题、音量等偏好设置
- **高分记录**: 记录每个关卡的最高分
- **统计数据**: 记录游戏时长、移动次数、合并次数等详细数据

### 8. 设置功能
- **主题切换**: 支持多种视觉主题
- **音量调节**: 音乐和音效音量独立控制
- **FPS 限制**: 可调节游戏帧率
- **粒子特效开关**: 开启/关闭粒子效果
- **3D 音效开关**: 开启/关闭 3D 音效
- **FPS 显示**: 实时显示游戏帧率

### 9. 教程系统
- **新手指引**: 详细介绍游戏玩法和操作
- **游戏规则**: 清晰说明游戏目标和规则

### 10. 统计数据
- **实时统计**: 游戏过程中显示当前分数、目标、时间等
- **详细统计**: 游戏结束后显示移动次数、合并次数、最高分、目标达成率等

## 技术特性

### 1. 多线程渲染
- **独立渲染线程**: 游戏逻辑和渲染分离
- **任务队列**: 使用队列管理渲染任务
- **60FPS 保证**: 精确的帧率控制

### 2. 粒子系统
- **多种粒子效果**: 合并、升级、游戏结束等特效
- **高性能渲染**: 优化的粒子绘制算法
- **动画支持**: 流畅的粒子运动和消失效果

### 3. 音效引擎
- **PyGame mixer**: 使用 Pygame 的音频系统
- **3D 音效**: 使用距离衰减模拟 3D 音效
- **动态音效**: 根据游戏状态变化音效

### 4. 数据管理
- **JSON 格式**: 使用 JSON 存储配置和数据
- **文件 I/O**: 安全的文件读写操作
- **错误处理**: 完善的异常处理机制

### 5. 兼容性
- **Python 2/3 兼容**: 支持 Python 2.7 和 3.x
- **跨平台**: 支持 Windows、macOS、Linux
- **UTF-8 编码**: 完整支持中文和其他 Unicode 字符

1024game/

│   ├── particle_system.py  # 粒子系统
│   ├── audio_system.py     # 音效系统
│   └── persistence.py      # 数据持久化

### 核心模块说明

#### 1. core/game_loop.py
- **功能**: 控制游戏主循环
- **主要类**: GameLoop、RenderThread
- **职责**:
  - 初始化游戏组件
  - 处理用户输入
  - 更新游戏状态
  - 协调多线程渲染

#### 2. core/game_logic.py
- **功能**: 实现游戏核心逻辑
- **主要类**: Game
- **职责**:
  - 方块移动和合并
  - 随机方块生成
  - 难度计算
  - 关卡目标判定

#### 3. core/particle_system.py
- **功能**: 粒子特效系统
- **主要类**: ParticleSystem
- **职责**:
  - 粒子创建和管理
  - 粒子动画更新
  - 粒子效果渲染

#### 4. core/audio_system.py
- **功能**: 音频播放系统
- **主要类**: AudioSystem
- **职责**:
  - 音效加载和播放
  - 3D 音效处理
  - 音量控制

#### 5. core/persistence.py
- **功能**: 数据持久化
- **主要类**: PersistenceManager
- **职责**:
  - 配置文件读写
  - 游戏进度保存
  - 成就跟踪

#### 6. ui/main_menu.py
- **功能**: 主菜单界面
- **主要类**: MainMenu
- **职责**:
  - 菜单显示
  - 事件处理
  - 界面导航

#### 7. ui/game_screen.py
- **功能**: 游戏界面渲染
- **主要类**: GameScreen
- **职责**:
  - 游戏区域绘制
  - 分数和状态显示
  - 主题管理

## 游戏流程

### 1. 启动流程
1. 运行 `main.py`
2. 初始化 Pygame
3. 创建 GameLoop 实例
4. 加载配置和进度
5. 显示主菜单

### 2. 游戏流程
1. 选择关卡
2. 初始化游戏逻辑
3. 进入游戏循环
   - 处理输入
   - 更新游戏状态
   - 渲染游戏界面
4. 检测游戏结束条件
5. 显示统计数据

### 3. 保存流程
1. 自动保存游戏进度
2. 自动保存设置更改
3. 游戏结束后保存统计数据

## 操作指南

### 键盘控制
- **方向键** 或 **W/A/S/D**: 控制方块移动方向
- **ESC**: 暂停游戏
- **R**: 重新开始当前关卡

### 鼠标控制
- 主菜单使用鼠标点击操作
- 设置界面使用滑块和按钮
